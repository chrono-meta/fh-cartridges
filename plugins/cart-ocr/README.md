# cart-ocr

Document OCR as a field tool: scanned PDF pages, photos and screenshots of documents (Korean + English, tables,
receipts, forms) in; a typed extract out (`kind: table | lines`), with a status on **every field**:
`VERIFIED` · `DISAGREE` · `AMBIGUOUS` · `SUSPECT` · `UNREADABLE` · `UNCHECKED` (not a pass).

The reading itself is done by the calling model's vision. The cartridge's machine part sits where a bare reader was
measured to fail silently (see EVIDENCE.md at the repository root):

| check | what it catches | lane |
|---|---|---|
| sum row | rows that do not add up to the printed total → `SUM-MISMATCH`, column `SUSPECT`; an unreadable row → `SUM-UNVERIFIABLE` | L3 |
| second engine (Apple Vision) | a number the calibrated engine read one character differently → `DISAGREE`; identical → `VERIFIED` | L5 |
| calibration | the engine must read a shipped known pair exactly before any of its reads counts | L7 |
| look-alike characters | codes mixing `I l O Q D S B Z G` with `0 1 2 5 6 8 |` that no second engine read identically → `AMBIGUOUS` | L4 |
| structure | rows with the wrong cell count; a receipt written as lines instead of a table | L1, L2 |
| PDF route | per page: text layer used only when the calibrated engine reads its numbers on the rendered print; a layer number one character off the print → `TEXT-LAYER-DISAGREE`, page goes to OCR; no layer → OCR; no poppler → `pdf SKIPPED` rc 2 | L11, L12 |
| multi-page | one `--engine` per page in a single `check` | L13 |
| typed channel | no engine → `ENGINE UNMEASURED` and `UNCHECKED`, never `VERIFIED`; `[UNREADABLE]` kept as `UNREADABLE` | L6, L8 |

## Engines

| engine | status | licence |
|---|---|---|
| model vision (the caller) | always — reads first, into `extract.json` | — |
| Apple Vision (`VNRecognizeTextRequest`, via `scripts/vision_ocr.swift`) | macOS with `swift` (Xcode CLT); otherwise `SKIPPED`, and `read` exits 2 | Apple system framework, used through the public API; nothing redistributed |
| poppler (`pdfinfo`, `pdftotext`, `pdftoppm`) | for `pdf` only; absent → `HARNESS-ERROR pdf SKIPPED` | GPL-2.0, called as an external program, not bundled |
| Tesseract | detected and reported (`OK` / `SKIPPED`), **not used** by this version | Apache-2.0 (not bundled) |

## Run

```
python3 scripts/ocr_check.py engines
python3 scripts/ocr_check.py read page.png > read.json          # calibrates first; rc 2 = engine UNMEASURED
python3 scripts/ocr_check.py pdf in.pdf pages/                 # ROUTE text-layer | ocr | text-layer-unverified per page
python3 scripts/ocr_check.py check extract.json --engine read.json [--engine page2.read.json ...] [--json]
python3 scripts/test_ocr_check.py            # lanes
python3 scripts/test_ocr_check.py --probes   # revert probes: each machine check removed → exactly its lane red
```
Exit codes: 0 no finding · 1 findings · 2 HARNESS-ERROR. `check` is a measurement engine (it reports field statuses);
FH should not read its rc 0 as «the extract is right» — rc 0 with `UNCHECKED` fields means nothing checked them.

Standard library only (Python); the Swift file uses Apple's Vision/AppKit. Clean-room: no third-party text or code.
`fixtures/calib.png` and `fixtures/pdf_*.pdf` are generated by this repo (`tools/ocr_fixtures/`), no external artefact.
